# Hotel Management System

A web-based Hotel Management System developed using PHP and MySQL to manage hotel operations, including room management, customer information, reservations, and billing.

## 📌 Project Overview

The Hotel Management System helps hotel staff manage daily activities through a centralized web application. It aims to simplify room booking, guest registration, reservation tracking, and payment management.

## 🚀 Features

- **Dashboard:** View an overview of hotel operations.
- **Room Management:** Add, update, view, and manage hotel rooms.
- **Customer Management:** Store and manage guest details.
- **Booking Management:** Create and manage room reservations.
- **Check-In / Check-Out:** Manage guest arrival and departure.
- **Billing and Payments:** Maintain customer bills and payment records.
- **Authentication:** Login functionality for authorized users.

*Note: The features listed above should be adjusted to match the actual functionality of your project.*

## ⚙️ Installation and Setup

### 1. Install Requirements

Install [XAMPP](https://www.apachefriends.org/) or another PHP-compatible local server with MySQL support.

### 2. Clone or Download the Project

Copy the project folder into your server's web directory.

For XAMPP:

```text
C:\xampp\htdocs\Hotel
```

### 3. Start the Server

Open the XAMPP Control Panel and start:

- Apache
- MySQL

### 4. Create the Database

1. Open `http://localhost/phpmyadmin/`.
2. Create a database named `hm`.
3. Import the project's SQL file if one is available.



Use the database credentials configured on your own server.

### 5. Run the Project

Open the following URL in your browser:

```text
http://localhost/Hotel/
```
